# Customer Churn Analytics Project

Course: CIS8005

## Project Scope

This project analyzed customer churn across Telecommunications, Retail Customer Churn, and Retail Sales datasets.

## Technologies

- Python
- Pandas
- SQLite
- MongoDB
- Matplotlib
- Scikit-learn

## Analytical Components

- Data Cleaning and Transformation
- Exploratory Data Analysis
- SQLite Analytics
- MongoDB Analytics
- Predictive Modeling
- Feature Importance Analysis
- Business Intelligence Recommendations

## Key Findings

- Telco churn is heavily influenced by pricing and customer value.
- Retail Customer Churn is strongly influenced by customer tenure and incentives.
- Retail Sales requires additional behavioral and engagement features to improve predictive performance.
